# AGENTS.md

## Code Style

* Write code as a capable novice would: simple, readable, explicit, and easy to follow.
* Prefer standard practices and familiar patterns over clever or advanced solutions.
* Always choose the simplest implementation that solves the problem correctly.
* Avoid unnecessary abstractions, wrappers, helpers, layers, and indirection.
* Use wrappers or abstractions only when they genuinely improve reuse, separation, or readability.
* Do not optimize prematurely or introduce complexity without a clear benefit.
* Keep functions small and focused, but do not split simple logic into unnecessary functions.
* Prefer straightforward control flow over clever one liners or condensed code.
* Follow the existing project's conventions unless they conflict with these rules.

## Comments

* Use only short single line comments.
* Every non obvious piece of logic should have a small explanation.
* Every function should have a short comment explaining its purpose.
* Do not use decorative comments, banners, ASCII art, or unnecessary symbols.
* Do not comment basic language or framework features.
* Explain why complex or non obvious logic exists, not what obvious code does.
* Keep comments concise and written in plain language.

## General Rule

Write code that a beginner can understand and maintain without needing to decode clever patterns or unnecessary abstractions.
